# 06 — Workflows

### Simple Daily Process

1. Capture new ideas → put in ideas/raw/
2. Score them → move to ideas/scored/
3. Kill weak ones → move to ideas/killed/
4. Keep good ones → move to ideas/alive/
5. Enrich the best ones (score 70+) → move to ideas/enriched/
6. When ready, create handoff package → move to ideas/ready_for_handoff/
