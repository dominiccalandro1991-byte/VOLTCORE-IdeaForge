# 03 — Scoring Rubric

Score every idea on these 5 things:

1. Novelty (25%) – How original is it?
2. Usefulness (25%) – Does it solve a real problem?
3. Scalability (20%) – Can it grow into a bigger system?
4. Automation Potential (15%) – Can AI/automation run a lot of it?
5. Longevity (15%) – Will it still matter in 5–10 years?

### Overall Score Guide

- 85–100 = Excellent (priority)
- 70–84 = Strong (enrich it)
- 50–69 = Weak but alive
- Under 50 = Kill it
