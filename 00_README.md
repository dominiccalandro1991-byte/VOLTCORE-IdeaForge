# VOLTCORE IdeaForge

**Status:** Active Foundation  
**Version:** 1.0.0  
**Created:** 2026-07-19  

---

## Purpose

VOLTCORE IdeaForge is the dedicated system for creating, scoring, filtering, and handing off new app and invention ideas.

Only strong ideas leave this system. Weak ideas are killed cleanly.

---

## Core Rules

1. Generate many ideas.
2. Score every idea.
3. Kill weak ideas without guilt.
4. Only send strong ideas to the App Engineer.
5. Learn from every idea (killed or successful).

---

## Folder Guide

- ideas/raw/ → New ideas go here first
- ideas/scored/ → After scoring
- ideas/alive/ → Ideas that passed the kill test
- ideas/enriched/ → Strong ideas with extra research
- ideas/ready_for_handoff/ → Fully ready to send to App Engineer
- ideas/handed_off/ → Successfully transferred
- ideas/killed/ → Weak ideas (keep them for learning)
- ideas/archive/ → Old finished ideas

---

## How to Use

1. Capture new ideas in ideas/raw/
2. Score them
3. Kill or keep them
4. Enrich the good ones
5. Create a handoff package
6. Send only the ready ones forward
